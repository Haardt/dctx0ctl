## Pinned work packages and measurable delivery

Export dependency-closed task packages with complete shared context, pinned
snapshot/check/event provenance, frozen profile attribution and deterministic
content identities. Package deltas transmit changed context and task state without
repeating unchanged bodies. Read-only progress reports retain endpoint changes,
intervening events and history links separately from current acceptance claims.

Native verification diagnostics now support compact summaries, filtered case
pages and exact case details. Read-only adoption previews use the guarded native
proof evaluator to explain current eligibility and blockers without publishing
results, rebasing task pins or creating claims. Imported or pruned evidence cannot
authorize adoption.

The three embedded agent skills now explain bounded work packages, delta handoffs,
focused diagnosis, guarded delivery and endpoint measurements. An optional external
usage-analysis script joins exported package IDs to supplied token counts and
execution receipts; it does not create execution evidence or billing estimates.
Five new release workloads measure package, progress and diagnostic costs.

## Site updates and recursive generation

The companion refreshes pinned task state without discarding selection and
separates task progress from verification evidence. Large evidence JSON is read
through bounded, stack-safe projections. Recursive value generation retains
productive alternatives when another alternative has no bounded inhabitants,
while unsupported or incomplete generation remains explicit.

Existing task definitions, compiler semantics and SQLite schemas are preserved.
The additive CLI/JSON exports are documented in
[the workflow guide](https://github.com/Haardt/dctx0ctl/blob/v0.2.8/docs/site/src/reference/workflow-efficiency.md).

## Validation

Publication requires fresh full validation and all five native platform gates.
The local development checks and release speed/RSS measurements are recorded
separately; the local ARM64 Go race probe is unavailable on its 39-bit VMA host.
No release-gate exception or benchmark baseline promotion is introduced.
